8 · Motion Principles（Framer Motion）
Spring — 快（入場 / 彈出）
type: "spring", stiffness: 400–520, damping: 14–18
用途：item 入場、badge 彈出、小元件 pop
Spring — 緩（大卡片 / 頁面轉換）
type: "spring", stiffness: 280–380, damping: 18–22
用途：modal 出現、hero element、SuccessOverlay
Spring — 佈局（tab / 選項切換）
type: "spring", stiffness: 300–400, damping: 20–22
用途：segmented control thumb、step dots
Fade / Slide（頁面 / 步驟切換）
duration: 0.22–0.38, ease: [0.4,0,0.2,1]
用途：AnimatePresence mode="wait" 頁面切換
Background transition
duration: 0.9, ease: default
用途：ambient gradient / background color 切換
Float / Idle（持續飄動）
animate: y:[0,-8,0], duration: 2.2–3.2, repeat:Infinity, ease:"easeInOut"
用途：avatar 懸浮、插畫主體。每個元素 delay 錯開 0.15–0.28s
DO 入場動畫從 opacity:0 + y:16–24 開始
DO 多個同類元素用 staggered delay（每項 +0.06–0.13s）
DON'T 不在同一頁面超過 3 個同時進行的 infinite 動畫
DON'T duration 不超過 0.5s（除背景漸層、float 以外）
9 · Layout & Composition Rules
頁面背景
Base: #09090b。Ambient gradient 用 radial-gradient(ellipse ...) 加在 pointer-events-none absolute inset-0 層，不直接改 body background。
Mobile first · Full-height layout
頁面用 h-[100dvh] overflow-hidden flex flex-col。避免 100vh（iOS safari 高度問題）。Bottom safe area 使用 pb-safe 或 pb-6。
Section 間距
主要 section 間距：gap-4 / space-y-4（16px）。卡片 padding：p-4（16px）或 px-5 py-4。Modal 頂層 padding：px-5 pt-5 pb-4。
Scrollbar（全站）
使用 globals.css 的 *::-webkit-scrollbar 設定：6px 寬，thumb rgba(255,255,255,0.12)，hover rgba(255,255,255,0.22)，track transparent。Firefox 用 scrollbar-color。
Divider
水平分隔線：border-b border-white/[0.05] 或 h-px bg-white/[0.05]。不使用實線灰色。
Empty State
置中 flex column，icon 用 emoji 或 SVG（40–48px），主文 text-zinc-400 text-sm，輔助文 text-zinc-600 text-xs，可選 CTA button（ghost 樣式）。
Shadow / Glow
Primary button glow：box-shadow: 0 6px 24px rgba(139,92,246,0.4)。Card shadow：0 8px 32px rgba(0,0,0,0.37)。Neon glow（特殊）：drop-shadow(0 0 12px rgba(139,92,246,0.5))。
